SecurePass Gen -- a terminal-based password generator built entirely on the Python standard library.

options:
  -h, --help            show this help message and exit
  -l LENGTH, --length LENGTH
                        Password length, 16 by default (must be between 4 and
                        128).
  --no-lowercase        Exclude lowercase letters (a-z). Included by default.
  --no-uppercase        Exclude uppercase letters (A-Z). Included by default.
  --no-digits           Exclude digits (0-9). Included by default.
  --no-symbols          Exclude punctuation/symbols. Included by default.
  --exclude-ambiguous   Exclude visually ambiguous characters (0/O, 1/l/I).
  --count COUNT         Number of passwords to generate, 1 by default.
  --output FILE         Save generated password(s) to FILE, in addition to
                        printing them.
  --secure              Use the 'secrets' CSPRNG module instead of 'random'
                        for character selection and shuffling. Recommended for
                        any password you will actually use -- see README for
                        why.
  -v, --verbose         Enable debug logging to stderr (generated passwords
                        are never logged).

Examples:
  securepass-gen -l 16
  securepass-gen -l 20 --no-symbols --exclude-ambiguous
  securepass-gen -l 24 --count 5 --secure
  securepass-gen -l 16 --output passwords.txt
